# Core Type Contracts & Tactical Layout Configurations

This document establishes the structural foundations of the application layer. It delivers the complete unified TypeScript specifications mapping all real-time payloads, followed by the Tailwind utility engine configurations custom-tailored for maximum high-contrast screen visibility under direct sun glare or low-light stadium environment profiles.

## 1. Unified TypeScript Type Specifications (`src/types/index.ts`)

This file acts as the compile-time data contract across the edge functions, state context hubs, and the hardware-accelerated rendering canvas viewport layer.

```typescript
// src/types/index.ts

/**
 * High-precision coordinates normalized to a 0-1000 grid space.
 * Maps seamlessly to physical stadium layouts regardless of screen pixel scaling ratios.
 */
export interface MapCoordinates {
	x: number;
	y: number;
}

/**
 * The internal structured representation of an active threat or event anomaly.
 * Processed by the GenAI Triage proxy and consumed by the GPU Canvas engine.
 */
export interface IncidentReport {
	id: string;
	tier: 1 | 2 | 3; // Tier 1: Critical Emergency, Tier 2: High Alert, Tier 3: Routine Operations
	status: 'OPEN' | 'DISPATCHED' | 'ON_SCENE' | 'CLOSED';
	rawText: string;
	timestamp: number;
	coordinates: MapCoordinates;
	extractedMetadata: {
		category: 'SECURITY' | 'MEDICAL' | 'CROWD' | 'FACILITIES';
		severity: 'CRITICAL' | 'HIGH' | 'MEDIUM' | 'LOW';
		locationSector: string;
		actionRequired?: string;
	};
}

/**
 * Core parameters governing active ground workers synced through the Edge Gating subsystem.
 */
export interface WhitelistUser {
	id: string;
	fullName: string;
	role: 'superadmin' | 'admin' | 'staff';
	specialty: 'security' | 'medical' | 'cleaning' | 'supervisor';
	assignedZone: string;
	status: 'ACTIVE' | 'DISPATCHED' | 'OFF_DUTY';
	phone_number: string;
	currentCoords?: MapCoordinates;
}

/**
 * Administrative directive dispatches pushed out by the central command hub operators.
 */
export interface DispatchDirective {
	id: string;
	incidentId: string;
	targetStaffPhone: string;
	directiveText: string;
	status: 'SENT' | 'ACKNOWLEDGED' | 'ON_SCENE' | 'RESOLVED';
	timestamp: number;
}

/**
 * Raw social streaming data frame constraints expected by Pipeline B.
 */
export interface SocialPost {
	handle: string;
	text: string;
	timestamp: number;
}

/**
 * Aggregated cluster outputs generated by the serverless social listening scanner.
 */
export interface ExtractedCluster {
	locationSector: string;
	thematicIssue: string;
	associatedHandles: string[];
	severityEstimation: 'CRITICAL' | 'HIGH' | 'MEDIUM' | 'LOW';
}
```

## 3. Hardware-Accelerated Layout Sheet Injection (`src/index.css`)

This style injection forces high-performance hardware layers to take processing precedence, minimizing browser re-paint routines during swift map movements.

```css
/* src/index.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

@layer base {
	body {
		@apply bg-slate-950 text-slate-100 antialiased selection:bg-blue-600/40 select-none;
		-webkit-tap-highlight-color: transparent;
	}
}

@layer utilities {
	/* Forces rendering contexts onto dedicated GPU execution threads */
	.gpu-layer {
		transform: translateZ(0);
		will-change: transform, opacity;
		backface-visibility: hidden;
	}

	/* Eliminates mobile interaction delays and elastic bounce scrolling quirks */
	.touch-surface-lock {
		touch-action: none;
		overscroll-behavior: contain;
	}

	/* Structural UI element optimized scroll bar track overrides */
	.custom-scrollbar::-webkit-scrollbar {
		width: 4px;
	}
	.custom-scrollbar::-webkit-scrollbar-track {
		background: rgba(15, 23, 42, 0.3);
	}
	.custom-scrollbar::-webkit-scrollbar-thumb {
		background: rgba(51, 65, 85, 0.6);
		border-radius: 9999px;
	}
}
```
